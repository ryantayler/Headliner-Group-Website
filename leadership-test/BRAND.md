# Brand, as used in this test

The Headliner Group identity, lifted from `assets/css/styles.css`. If the site
changes, change it there first and copy the tokens across.

## Colours

```css
--base:#0A0A0A  --panel:#111111  --rim:#2E2E2E     /* dark surfaces */
--ink:#ECE8E0   --sub:#ADA9A3    --mute:#7C7C7C    /* text on dark */
--paper:#F2F4F3 --paper-2:#E7EBE9 --card:#FFFFFF   /* light surfaces */
--ink-l:#111614 --sub-l:#3F4744  --mute-l:#5B6360  /* text on light */
--accent:#2DE2C3       /* aqua, on dark */
--accent-deep:#0A7261  /* aqua deepened so it carries text on light */
--cta:#FF5A36          /* coral, buttons only */
```

Dark at the ends, light through the middle. The intro and the result reveal
are dark bands with the background shaft. The questions and the result cards
are on paper.

## Fonts

```html
<link href="https://fonts.googleapis.com/css2?family=Archivo+Black&family=Inter:wght@400;500;600&display=swap" rel="stylesheet">
```

- **Archivo Black** headings, uppercase, and the logo.
- **Inter** everything else.
- No Anton, no Caveat. Those are Ryan's personal brand, not the group's.

## Rules

- Aqua is the only brand accent. Coral is the primary button and nothing else.
- The logo block is the site's, byte for byte. Do not edit it.
- Print styles exist for light and dark. Test both before shipping.
